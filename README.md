# Hormuz Trade & Continental Economic Analysis

## Project Overview
This project focuses on analyzing international maritime trade patterns and economic activities associated with the Strait of Hormuz. The analysis examines continent-wise trade performance, trade growth trends, and comparative economic patterns using data analytics and visualization techniques.

The project applies time-series analysis, comparative analytics, and correlation analysis to identify global trade trends and provide strategic economic recommendations.

---

## Objectives

- Analyze continent-wise trade activity and economic contribution
- Compare monthly trade growth trends
- Perform comparative analytics across continents
- Visualize trade patterns using graphs and heatmaps
- Identify relationships between economic trade variables
- Generate strategic recommendations for improving trade stability

---

## Dataset

Dataset Used:

`hormuz_trade_tier_continental_2026.csv`

The dataset contains maritime trade-related information including:

- Trade routes
- Cargo value
- Transit costs
- Delays
- Insurance costs
- Trade destinations
- Continents
- Risk-related variables
